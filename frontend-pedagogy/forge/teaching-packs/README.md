# FE teaching packs

**Two different kinds of pack live under this directory — do not read them
the same way.**

The flat `unit-N-*.md` files here are **FE II** — forge targets for
content not yet built, tagged `pilot`/`gap`/`ready-to-upgrade` against the
classical-didactics evidence matrix (`../../grounding/README.mdc`). They
close the structural gap between researched unit prose and a teachable
production lesson, and deliberately do not promote unsupported pedagogy
claims. Forge order: Units 11–12, then 2–4/7, then 8–10, then 1.

**[`fe-i/`](fe-i/)** is a different genre entirely: FE I's **already-
delivered** track, added 2026-08-19 — 20 real, taught, live-URL units
across two semesters, `status: delivered`, not `pilot`. Read `fe-i/README.md`
before assuming FE I units follow the same "gap declared, needs grounding"
framing as the FE II files in this directory — they don't; their authority
is their own delivery record, a literature citation is optional backfill
for them, not a gate.

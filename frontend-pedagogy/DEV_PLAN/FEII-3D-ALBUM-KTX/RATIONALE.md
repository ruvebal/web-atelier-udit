# Why this cascade

FE II Bloque 5 is already an **interface-layer transfer** exercise. Students currently defend a beacon. The pitch is a **web 3D version of a favourite album cover**, handed in as a **route** on **one instructor-owned GitHub aggregator** so every cover is a URL the instructor can open.

## What ships

1. **Retargeted Units 8–9 assignment** — covenant bars + KTX2 choice + IP line. Hand-in = TTOD-shaped PRs that light `/covers/<slug>` (named branches, small PRs, AI Review Log, human merge).
2. **Two satellite lessons** (not Units 13–14): cover shaders; KTX2 taught from `<img>` → pixel/texel → GPU memory → ETC1S vs UASTC ([KTX2-FIRST-PRINCIPLES.md](KTX2-FIRST-PRINCIPLES.md)).
3. **GitHub aggregator** `ruvebal/feii-album-covers` (private) — gallery + `/covers/_studio` + `/covers/<slug>` student routes. Shape: [REPO-SHAPE.md](REPO-SHAPE.md).

## Creating the repo — not `index.md` as a factory

**Question:** can the instructor follow `private/ai-assisted-3d/index.md` / `corpus-to-boilerplate/` to create this repo?

**No as a paste-and-generate prompt.** `AUDIT-GROUNDED.md` already split that module: student path is the covenant + Units 8–9; corpus-to-boilerplate is prospector overskill (SSR, i18n, Hygraph, p5, splats). Running it would emit a studio monorepo the assignment does not grade.

**Yes as a recycle list:** philosophy, merge rubric, rules-first, cursor-rules 20/30/40/50, KTX2 pipeline notes, JSDoc. Runnable pins come from `react-template`. That mapping is D7 + REPO-SHAPE.md.

## What this is not

- A 13th numbered unit.
- MCP / Stitch / corpus-to-boilerplate on the student path.
- N student GitHub repos (the promise to the cohort was **one aggregator**, many **routes**).
- A new git culture. Contribution is TTOD’s (`qa-007`; `contributing.md`), mapped onto cover routes (D21).
- A public dump of copyrighted sleeves in `_studio`.

## Autopilot

The cascade is written to run X0→X12 with agent cold review and without a human clipboard for Pass 1. See [AUTOPILOT.md](AUTOPILOT.md). Publishing **web-atelier** Pages remains a human `git push`.

## Success

The instructor opens `/`, then each `/covers/<slug>`. A team can explain their shader, say pixel vs texel, show file bytes vs GPU texture memory, and name ETC1S or UASTC with a reason. `/covers/_studio` has no Beatles JPEG.

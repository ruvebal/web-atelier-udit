# Phase X6 — Starter, gallery and competition rehearsal

## Goal

Make the assignment ready for a student who has never touched the instructor host.

## Entry gate

PHASE-X5-REPORT.md is DONE with evidence and cold-review disposition. Recheck facts on the target environment.

## Deliverables

Starter template; contribution ritual; common audio pack; scoring sheets; demo/defence schedule; timed rehearsal and fixes.

## Scope

One plugin per student and shared player. Public repo creation/publication only when requested; no real student grades or identifiers in public fixtures.

## Implementation prompt

Template — execute only after the entry gate passes.

```text
Read INDEX, TECHNICAL-DIRECTOR-CASCADE, SOURCES and this runbook.
Have an independent tester use the starter and submit a distinct plugin using only student instructions. Rehearse setup and A1/A2/A3 increments, including individual tasks. Apply the design skill to gallery/player polish. Freeze final device budgets, permissions, rubric and deadlines from actual course data. Preserve feedback history without making prize votes determine grades.
Run the Acceptance checks below and record actual commands and exits.
Do not mark DONE; hand off the packet for fresh local Qwen cold review.
Use the orchestrator's closing protocol and amend-on-surprise rule.
```

## Acceptance

- [ ] A fresh tester builds and submits a plugin without private corpus/tools or undocumented host edits.
- [ ] CI validates manifest, kernel tests, artifacts/licences and host integration; no generated credentials enter submissions.
- [ ] Timed rehearsal supports the class duration; setup trouble has a working prebuilt fallback and does not erase core Rust contribution.
- [ ] Competition rubric totals 100%; all entry requirements have an observable test; demo schedule fits confirmed cohort size.
- [ ] Keyboard, reduced motion, silent mode, network outage and renderer loss are demonstrated on target hardware; release report and cold review complete.

## Risks

Installation consumes the studio; unequal hardware/access; hidden instructor steps; competition displacing individual understanding.

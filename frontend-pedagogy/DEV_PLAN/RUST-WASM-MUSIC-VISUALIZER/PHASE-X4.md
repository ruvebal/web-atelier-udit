# Phase X4 — Rive comparison adapter

## Goal

Make Rive a credible, bounded expressive option using the same feature and lifecycle contract.

## Entry gate

PHASE-X3-REPORT.md is DONE with evidence and cold-review disposition. Recheck facts on the target environment.

## Deliverables

Rive control/state adapter; common-input comparison; feature-support matrix; reproducible assets/runtime pins; optional true-3D proof.

## Scope

Promote Rive Wasm integration and verify capabilities. A recorded WAV, 2D vector or included runtime binary is not student Rust/GPU-3D evidence.

## Implementation prompt

Template — execute only after the entry gate passes.


## Acceptance

- [ ] Same captured feature fixture drives both adapters; pause/seek/reset and reduced motion behave coherently.
- [ ] Rive package, Wasm binary and asset versions/locations are recorded and load without console/network failures.
- [ ] Main audio is not duplicated; no unverified browser AudioWorklet/sample-lock claim appears.
- [ ] Any true-3D claim has depth-tested occlusion, camera/picking proof and target-browser evidence; otherwise explicitly excluded from that lane.
- [ ] Asset source/licence/access requirements and free baseline alternative are documented; cleanup and full host tests pass.

## Risks

Editor/runtime version mismatch; premium authoring constraints; COI/threading requirements; 2.5D mislabelled as 3D.

# PASS 1 — Map · critical Contidos bibliography (bilingual ES / EN)

**Role:** map **critical** references on **cutting-edge AI-assisted coding methodologies and their critiques** for Contidos / Temario in front-end / computing education. Pass 2 audits on another model; Pass 3 merges. Prefer precision over coverage.

Students will use LLMs professionally. Contidos must include sources that teach **method** (scaffolding, deferred help, human-in-the-loop review, process evidence) **and** sources that name **failure modes** (cognitive offloading, false mastery, shallow learning, unfair assessment, solution dumping). This is critique + method — not ChatGPT tip lists.

## Critical anchors (one subsection each)

1. **Cognitive offloading and false mastery** — students produce artefacts they cannot explain; fear of assessment without the assistant; “finishing” vs learning under deadline pressure
2. **Scaffolding that withholds solutions** — assistants and hint systems designed to support without revealing full code answers; Zone of Proximal Development framings used honestly (not as slogan)
3. **Deferred / timed AI assistance and metacognitive scripting** — access timing, planning/monitoring/evaluation hints, detection of omitted errors in AI hints
4. **Human-in-the-loop AI code review** — AI as PR reviewer; false positives; ACCEPT/REJECT responsibility; teaching review prompts as assessable skill (not as labour replacement)
5. **Assessment integrity by design** — AI-use declarations, oral code defence, process/version evidence, student demand for fairness; faculty ethics concerns as **faculty** evidence (do not conflate with student outcomes)
6. **Hype critique and industrial concentration** — critical takes on GenAI in programming education and creative/engineering labour; authorship; who owns the pipeline — critique only, not vendor onboarding

Mark programming-general / data-science classroom studies `scope: programming-general` when they are transferred to front-end teaching; do not pretend they are web-cohort evidence.

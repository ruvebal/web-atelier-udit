# Phase 1: Contract

Prompt for a cold session:

> Define the public figcaption data contract and private provenance contract
> for immutable formula-driven SVG/PNG assets. Require authorship, ISO date,
> title, description, formula UUID and SHA-256, Chicago citation, delivery
> paths, and accessible figcaption text. Keep Ahmes internal evidence private.
> Return JSON examples, compatibility rules, and failing validation cases. Do
> not implement rendering or change publication content.

Gate: the public schema contains no local source-system metadata, while the
private schema can reproduce the source-page audit.

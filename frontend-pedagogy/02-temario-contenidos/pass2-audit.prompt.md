# PASS 2 — Independent audit (verification only)

**Role:** you are an **auditor, not a co-author**. A different model produced the bibliography map below for Contidos / Temario (**front-end / interface-layer development pedagogy** in higher education). **Verify it. Do not extend it** with new topics or a rewritten map.

Use a **different** research surface than Pass 1 (adversarial independence).

## What to check

1. For every claim tagged `[ESTABLISHED]` or `[EMERGING]`, try to corroborate it independently. Flag anything you cannot, even if it sounds plausible.
2. For every citation, verify that **author / title / year / venue** match a real record.
3. For every `doi:` value: confirm it resolves (or state that you could not resolve it). Flag fabricated, truncated, or mismatched DOIs.
4. For every `isbn:` value: confirm it matches that title (or state unverifiable). Flag invented or wrong ISBNs.
5. Items marked `status: no-doi-no-isbn` — say whether a DOI or ISBN **does** exist and should be filled, or whether the item should be dropped.
6. Note contradictions (dates, author lists, “et al.” on single-author works, venue misattribution, priority claims).
7. `missing:` only for **material** canonical or technical sources a specialist would expect **inside the same anchors** — not a new syllabus. Do not pad.
8. Flag **scope collapse**: general CS1 / Python / data-science education papers presented as if they were web- or front-end-specific evidence. Mark them `disputed:` with a scope note, or `confirmed:` only if the map already labelled them adjacent / transfer.

## Output vocabulary (mandatory)

One bullet per audited item, each starting with exactly one of:

- `confirmed:`
- `disputed:`
- `unverifiable:`
- `missing:`

Name the claim or citation judged. Where you dispute, state the correction plainly (correct DOI/ISBN/title/authors if you have them).

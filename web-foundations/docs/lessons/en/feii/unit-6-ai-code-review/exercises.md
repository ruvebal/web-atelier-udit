# Unit 6 exercises — individual, decontextualised

Use the three B3 tasks in the lesson's Individual exercises section. The team
may share the repository workflow; the judgement record is individual.

## Professor expected-answer sketch

1. The stronger prompt limits the diff, requests a fixed issue format, asks for
   uncertainty, and prevents praise or unbounded commentary.
2. A valid ACCEPT cites a concrete user, accessibility, correctness, or
   maintainability consequence and an implementation diff.
3. A valid REJECT explains why the suggestion is unmeasured, out of scope,
   premature, or inconsistent with the project contract. “The AI was wrong” is
   not a reason.
4. An ESCALATE is appropriate for a new dependency, a security-sensitive
   decision, or a product requirement the PR cannot determine.
5. The reflection distinguishes evidence about this project from a general claim
   that AI review improves learning or code quality; the latter remains
   BIBLIO-GAP in this lesson.

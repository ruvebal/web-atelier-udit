# Unit 6 deck outline — 1 h

1. AI review is a workflow, not an authority
2. The evidence boundary: the in-workflow outcome study is BIBLIO-GAP
3. What the course actually assesses: documented human judgement
4. A useful review prompt: role, scope, output format, uncertainty
5. Do not praise: reduce flattery and preserve reviewer attention
6. Permission design: comments only, never autonomous approval or merge
7. The loop: open PR → AI comment → accept/reject/escalate → human approval
8. A rejection with a reason is evidence of competence
9. Keep secrets and personal data out of model-bound diffs
10. Entrega 1 evidence: review log, implementation diff, tests, declaration
11. Handoff to Unit 7: measure performance advice before accepting it

Speaker claims only. The review loop is a transparent course contract, not a
claim that AI review has already been shown to improve learning in this cohort.

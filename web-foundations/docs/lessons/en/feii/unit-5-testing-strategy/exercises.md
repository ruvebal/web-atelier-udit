# Unit 5 exercises — individual, decontextualised

Use the three B3 tasks in the lesson's Individual exercises section. Submit the
written parts independently of the team lab artefact.

## Professor expected-answer sketch

1. A sensible deletion names an implementation-detail test, a framework test, or
   a static snapshot with no meaningful branch. The reason must describe why the
   user-visible contract remains covered elsewhere.
2. A flake diagnosis identifies one causal class (time, order, network, or
   animation/focus) and fixes the condition rather than increasing a timeout.
3. The CI record reports observed wall-clock values, not a guessed saving.
4. The contract-test explanation distinguishes a stable field shape from a
   mutable production value. It should name one breaking rename that MSW would
   not reveal.
5. Accessibility automation is accepted only as a floor. The answer must retain
   a manual keyboard or screen-reader check.

Do not reward more tests by default. Reward an explicit, defensible confidence
gain for the maintenance cost.

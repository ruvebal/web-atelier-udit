## Professor expected-answer sketch (not published on the student page)

1. **Diagnostic:** "single interface" claims (one component tree, one deploy target, one rendering context) change; "props/state/lifecycle" claims do not. A student who claims *everything* changes has over-generalised the reframe; a student who claims *nothing* changes has missed it.
2. Expected shape: AI-sped-up completion proves the *task* finished faster; it does not prove the student can explain *why* the solution works, extend it, or debug it without the tool — the distinction between immediate performance and durable learning introduced in the lesson.
3. No single correct prediction — check for a defensible line of reasoning back to the systems-lens framing (Unit 2: islands as a system-of-rendering-contexts choice; Unit 8: R3F as the interface layer transferred past the DOM), not a lucky guess.
